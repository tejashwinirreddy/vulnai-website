
# VULNAI Website

## AI-Driven Vulnerability Risk Scoring and Prioritization

VULNAI is a research and educational cybersecurity project focused on machine learning-based vulnerability risk scoring and prioritization.

The website introduces the VULNAI platform and provides access to its interactive vulnerability analysis dashboard.

## Features

- Machine learning-based vulnerability risk scoring
- XGBoost classification
- CVSS severity analysis
- EPSS exploitation probability indicators
- CISA Known Exploited Vulnerabilities (KEV) integration
- SHAP explainability
- Vulnerability prioritization
- Nmap and OWASP ZAP scanner report integration
- Remediation guidance

## Purpose

This project explores the application of machine learning and explainable AI in cybersecurity vulnerability assessment and remediation prioritization.

## Disclaimer

VULNAI is a research and educational prototype. Its risk scores are decision-support estimates and should not be treated as guarantees of real-world exploitation. Scan only systems you own or have explicit permission to test.
