ABOUT THE PROJECT

Understanding Vulnerability Risk Beyond Severity

Traditional severity scores alone do not always indicate which vulnerabilities are most likely to be exploited. VULNAI combines multiple security indicators with asset context to produce a prioritized vulnerability ranking.

3,439 CVEs Analysed

The current project dataset contains 3,439 vulnerability records for risk analysis.

Machine Learning

An XGBoost classification model estimates exploitation risk using selected vulnerability indicators.

Explainable AI

SHAP explanations help users understand which input features contribute to model predictions.

PLATFORM CAPABILITIES

What VULNAI Offers

A unified approach to cybersecurity vulnerability analysis, risk scoring and remediation prioritization.

🧠

ML-Based Risk Scoring

Uses an XGBoost model to estimate exploitation risk from vulnerability-related features.

🎯

Vulnerability Prioritization

Combines model risk with asset criticality and internet exposure to rank vulnerabilities.

📊

CVSS and EPSS Analysis

Uses technical severity and exploitation probability indicators to support risk analysis.

🔍

SHAP Explainability

Provides feature-contribution explanations to make model outputs easier to interpret.

🛡️

Scanner Report Integration

Supports importing Nmap and OWASP ZAP reports for vulnerability review.

📋

Remediation Guidance

Presents prioritized findings with suggested remediation actions and illustrative timelines.
